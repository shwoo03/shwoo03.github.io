### 문제 개요
{: id="문제-개요"}

Mongod는 MongoDB 데이터베이스와 MongoDB 셸 유틸리티를 사용하여 데이터베이스와 상호작용하는 방법을 소개하는 매우 쉬운 난이도의 Linux 머신입니다.

데이터베이스에서 익명 사용자(Anonymous User)의 접근을 허용하는 잘못된 설정으로 인해 공격자가 이를 악용하여 데이터베이스의 모든 정보를 열거하고 조회할 수 있음을 보여줍니다.

### TASK8
{: id="task8"}

> Submit the flag located in the database.

mongosh 가 설치가 안되어있음 ;;;;

```plaintext
sudo apt update
sudo apt install mongodb-mongosh
```

다음 명령어로 접속 시도

```plaintext
mongosh mongodb://10.129.228.30
```

<code>mongosh 2.14.0</code> (MongoDB 4.2 이상 필요);;;;;;;; 따라서 구 버전 접속 방법인 mongo 로 접속

```plaintext
wget https://fastdl.mongodb.org/linux/mongodb-linux-x86_64-debian10-4.4.31.tgz

tar -xzf mongodb-linux-x86_64-debian10-4.4.31.tgz

wget 'https://archive.debian.org/debian-archive/debian-security/pool/updates/main/o/openssl/libssl1.1_1.1.1w-0+deb11u8_amd64.deb' -O libssl1.1.deb

mkdir -p ~/mongo-libs

dpkg-deb -x libssl1.1.deb ~/mongo-libs

LD_LIBRARY_PATH="$HOME/mongo-libs/usr/lib/x86_64-linux-gnu" \
./mongodb-linux-x86_64-debian10-4.4.31/bin/mongo \
--host 10.129.228.30 --port 27017
```
