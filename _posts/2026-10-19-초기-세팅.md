### 디스코드 봇
{: id="디스코드-봇"}

디스코드를 보면 다음과 같이 CTF면 티켓을 처리할 수 있는 앱이나 노래를 틀어주는 앱 같은 것들을 볼 수 있음<br>그 외에도 많은 앱들이 마켓 플레이스에 존재함

디스코드 봇은 부여받은 권한 안에서 서버를 관리하고, 명령어 실행, 메시지 전송, 외부 서비스 연동 등의 기능을 수행할 수 있음

이러한 기능들은 디스코드에서 공식적으로 제공하는 API 와 상호작용 기능을 활용하여 구현할 수 있음

#### 봇 실행 환경 구축하기
{: id="봇-실행-환경-구축하기"}

사실 이후에는 코덱스한테 만들어달라고 하긴 했는데 직접 조금 해봤음

디스코드 앱이 동작하려면 내 컴퓨터에서 디스코드 앱 동작 로직을 짜서 구동시켜 줘야한다. 나는 WSL Ubuntu26.04 환경에서 구축했고 다음과 같이 라이브러리를 다운로드 함.

```plaintext
python -m pip install -U discord.py python-dotenv
```

.env 파일에 디스코드 Bot 탭에서 받은 토큰을 준비하고 테스트 서버에 앱을 초대해놓으면 됨

대충 처음 초대해서 채널이나 그런거 다 설정하도록 하는 코드는 이런 느낌임 구현은 당연히 AI가 해줬고 앞으로 기능은 모두 설계도만 내가 만들고 구현은 모두 AI한테 해달라고 할꺼임

```typescript
export const botPermissions =
  P.ViewChannel |
  P.SendMessages |
  P.ReadMessageHistory |
  P.ManageChannels;

export class LiveDiscord implements DiscordAdapter {
  client = new Client({
    intents: [GatewayIntentBits.Guilds],
    allowedMentions: { parse: [] },
    rest: {
      timeout: 20000,
      rejectOnRateLimit: data =>
        data.method === "PATCH" && data.route === "/channels/:id",
    },
  });

  constructor(public db: PrismaClient) {}

}


async mapping(gid: string, key: string) {
  return (
    await this.db.guildChannelMapping.findUnique({
      where: { guildId_key: { guildId: gid, key } },
    })
  )?.discordId;
}

async save(gid: string, key: string, id: string) {
  await this.db.guildChannelMapping.upsert({
    where: { guildId_key: { guildId: gid, key } },
    create: { guildId: gid, key, discordId: id },
    update: { discordId: id },
  });
}

async category(g: Guild, key: string, name: string, aliases: string[] = []) {
  const mapped = await this.mapping(g.id, `cat:${key}`);
  let c = mapped ? g.channels.cache.get(mapped) : undefined;

  if (!c) {
    c = g.channels.cache.find(v =>
      v.type === ChannelType.GuildCategory &&
      [name, ...aliases].includes(v.name)
    );
  }

  if (!c) {
    c = await g.channels.create({
      name,
      type: ChannelType.GuildCategory,
    });
  }

  if (c.type !== ChannelType.GuildCategory) {
    throw new AppError(409, "저장된 카테고리 매핑의 유형이 다릅니다.");
  }

  if (c.name !== name) await c.setName(name);

  await this.save(g.id, `cat:${key}`, c.id);
  return c;
}

async channel(
  g: Guild,
  key: string,
  name: string,
  parent: string,
  type: ChannelType.GuildText | ChannelType.GuildVoice,
  aliases: string[] = [],
) {
  const mapped = await this.mapping(g.id, key);
  let c = mapped ? g.channels.cache.get(mapped) : undefined;

  if (!c) {
    c = g.channels.cache.find(v =>
      v.type === type && [name, ...aliases].includes(v.name)
    );
  }

  if (!c) c = await g.channels.create({ name, type, parent });

  if (c.type !== type) {
    throw new AppError(409, "저장된 채널 매핑의 유형이 다릅니다.");
  }

  if (c.parentId !== parent) {
    await c.setParent(parent, { lockPermissions: false });
  }
  if (c.name !== name) await c.setName(name);

  await this.save(g.id, key, c.id);
  return c;
}
```
