### CTFd 인증 방식 
{: id="ctfd-인증-방식"}

#### 비로그인 방식 
{: id="비로그인-방식"}

여러 가지가 존재하는데 가장 대표적인 것은 비로그인 방식임 로그인 안해도 바로 ctfd 접속해서 문제 해결 가능 

<div class="notion-blank"></div>

#### API Token 
{: id="api-token"}

로그인한 사용자가 API Token 을 발급받아서 요청마다 사용하는 방식임 

Settings → Access Tokens → Generate 으로 생성 가능하고 이거를 Discord 에 입력해서 사용 가능함
